# LINEFREE – Virtual Queue Management System  

🚀 **LINEFREE** is a mobile app that helps customers join queues virtually, reducing waiting times and improving overall experience. Instead of standing in line, users can track queue status in real-time, see estimated wait times, and even explore nearby places while waiting.  

---

## 📱 Features  
- Join a queue remotely from your phone  
- Real-time updates of queue status  
- Estimated waiting time per person  
- Location-based suggestions for nearby places  
- Separate panels for Customers and Admins  
- Built using **React Native (frontend)** + **Django (backend)** + **SQLite (database)**

## ⚙️ Tech Stack  
- **Frontend:** React Native  
- **Backend:** Django REST API  
- **Database:** SQLite  
- **APIs:** Axios for communication  

---

## 📂 Project Setup  

### Prerequisites  
- Node.js & npm  
- Python 3 & Django  
- Android Studio and Virtual device

### Steps  
1. Clone the repository  
   ```bash
   git clone https://github.com/vivekrathod260/LineFeeApp.git

2. Clone the QueueAPI backend server  
   ```bash
   git clone https://github.com/vivekrathod260/QueueAPI.git
   cd QueueAPI

3. Run Backend server
   ```bash
   python manage.py runserver

3. Go to LineFeeApp folder and Install npm packages
   ```bash
   npm install

4. Run App
   ```bash
   expo start
